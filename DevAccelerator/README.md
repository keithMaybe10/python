# DevAccelerator - 开发者网站访问加速器

## 项目简介

DevAccelerator是一款专为中国开发者设计的网站访问加速工具，通过智能DNS解析、代理转发等技术，显著提升GitHub、GitLab、npm、Docker Hub等开发网站的访问速度和稳定性。

## 主要特性

### 🚀 核心功能
- **零配置启动**: 自动生成和安装CA证书，一键启动即可使用
- **多站点支持**: 支持GitHub、GitLab、npm、Docker Hub、PyPI等开发网站
- **智能节点管理**: 自动测速、智能切换、故障转移
- **实时监控**: 连接状态、速度统计、流量统计可视化展示

### 🎨 用户体验
- **现代化界面**: 基于PySide6，采用Ant Design设计风格
- **任务可视化**: 实时显示下载进度、连接状态
- **系统集成**: 支持系统托盘、开机自启
- **跨平台支持**: Windows、Linux、macOS全平台支持

### 🛡️ 技术特性
- **自愈机制**: 自动故障检测和恢复
- **安全可靠**: 自签名CA证书，本地加密代理
- **高性能**: 异步处理，支持高并发
- **可扩展**: 模块化设计，支持插件和自定义规则

## 系统要求

- Python 3.8+
- 支持的操作系统：Windows 10+、macOS 10.14+、Linux
- 内存：至少512MB可用内存
- 网络：需要互联网连接

## 使用指南

### 首次使用

1. **启动程序**: 运行DevAccelerator
2. **安装证书**: 程序会自动提示安装CA证书（需要管理员权限）
3. **启动加速**: 点击"启动加速"按钮
4. **配置代理**: 根据提示配置系统代理（可选）

### 基本操作

#### 启动加速服务
- 点击主界面的"启动加速"按钮
- 程序会自动扫描并选择最优节点
- 启动成功后，状态显示为"运行中"

#### 查看节点状态
- 主界面显示各站点的连接状态和延迟
- "节点管理"标签页可查看详细的节点信息
- 支持手动测试和切换节点

#### 添加自定义节点
- 点击"添加节点"按钮
- 选择站点类型，输入IP地址和域名
- 系统会自动测试节点可用性

#### 查看运行日志
- "运行日志"标签页显示详细的运行信息
- 支持按日志级别过滤
- 可清空或导出日志

### 高级配置

#### 系统代理配置
程序提供以下代理端点：
- HTTP代理：`http://127.0.0.1:8080`
- HTTPS代理：`http://127.0.0.1:8443`
- DNS服务器：`127.0.0.1`

#### 自定义规则
- 支持添加自定义域名和IP映射
- 可配置特定站点的代理规则
- 支持导入/导出配置文件

## 常见问题

### Q: 启动时提示"端口被占用"？
A: 请检查端口53、8080、8443是否被其他程序占用，可在设置中修改端口。

### Q: 证书安装失败？
A: 请以管理员权限运行程序，或手动安装`certs/ca.crt`证书到系统信任库。

### Q: 某些网站仍然无法访问？
A: 请检查网站是否在支持列表中，可手动添加自定义节点。

### Q: 速度提升不明显？
A: 请尝试刷新节点或手动选择延迟更低的节点。
