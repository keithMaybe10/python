# DevAccelerator 使用指南

## 🚀 快速开始

### 1. 运行程序
```bash
python run.py
```

### 2. 启动加速
- 点击主界面的"启动加速"按钮
- 程序会自动生成CA证书并开始扫描节点
- 等待状态显示为"运行中"

### 3. 配置代理（可选）
程序提供以下代理端点：
- **HTTP代理**: `http://127.0.0.1:8080`
- **HTTPS代理**: `http://127.0.0.1:8443`
- **DNS服务器**: `127.0.0.1:5353`

## 🔐 证书安装

### 为什么需要安装证书？
- DevAccelerator使用HTTPS代理来加速访问
- 需要安装CA证书以避免浏览器安全警告
- 不安装证书也可以使用，但会有安全提示

### 如何安装证书？
1. 点击主界面的"证书安装"按钮
2. 按照弹出对话框中的步骤操作
3. 重启浏览器使证书生效

### 各系统安装方法

#### Windows
1. 找到证书文件（通常在 `certs/ca.crt`）
2. 双击证书文件
3. 点击"安装证书"
4. 选择"当前用户"或"本地计算机"
5. 选择"将所有的证书都放入下列存储"
6. 点击"浏览"，选择"受信任的根证书颁发机构"
7. 点击"确定"完成安装

#### macOS
1. 双击证书文件
2. 在钥匙串访问中找到 "DevAccelerator Root CA"
3. 双击证书，展开"信任"部分
4. 将"使用此证书时"设置为"始终信任"
5. 关闭窗口并输入密码确认

#### Linux
**方法一：系统级安装**
```bash
sudo cp certs/ca.crt /usr/local/share/ca-certificates/devaccelerator.crt
sudo update-ca-certificates
```

**方法二：浏览器导入**
- Firefox: 设置 → 隐私与安全 → 证书 → 查看证书 → 证书机构 → 导入
- Chrome: 设置 → 高级 → 隐私和安全 → 管理证书 → 受信任的根证书颁发机构 → 导入

## 🌐 网络配置

### DNS配置
由于使用非特权端口5353，需要手动配置DNS：

#### Windows
1. 打开"网络和共享中心"
2. 点击"更改适配器设置"
3. 右键网络连接 → "属性"
4. 选择"Internet协议版本4" → "属性"
5. 选择"使用下面的DNS服务器地址"
6. 首选DNS服务器：`127.0.0.1`
7. 备用DNS服务器：`8.8.8.8`

#### macOS
1. 系统偏好设置 → 网络
2. 选择当前网络连接 → "高级"
3. "DNS"标签页
4. 添加DNS服务器：`127.0.0.1`

#### Linux
编辑 `/etc/resolv.conf`：
```
nameserver 127.0.0.1
nameserver 8.8.8.8
```

### 浏览器代理配置（可选）
如果不想配置系统DNS，可以配置浏览器代理：

#### Chrome/Edge
1. 设置 → 高级 → 系统 → 打开代理设置
2. HTTP代理：`127.0.0.1:8080`
3. HTTPS代理：`127.0.0.1:8443`

#### Firefox
1. 设置 → 网络设置
2. 手动代理配置
3. HTTP代理：`127.0.0.1:8080`
4. HTTPS代理：`127.0.0.1:8443`

## 📊 功能说明

### 主界面
- **状态显示**: 显示当前运行状态
- **站点卡片**: 显示各网站连接状态和延迟
- **代理配置**: 显示代理端点信息
- **实时指标**: 显示运行时间、请求数等统计

### 节点管理
- **自动扫描**: 程序会自动扫描GitHub等网站的可用IP
- **手动添加**: 可以添加自定义的IP地址和域名
- **节点测试**: 测试节点的可用性和延迟
- **智能切换**: 自动选择最快的节点

### 运行日志
- **实时日志**: 显示程序运行的详细信息
- **级别过滤**: 可以按日志级别过滤显示
- **错误排查**: 出现问题时查看错误信息

## ❓ 常见问题

### Q: 程序启动失败？
A: 检查以下几点：
1. Python版本是否 >= 3.8
2. 是否安装了所有依赖：`pip install -r requirements.txt`
3. 端口5353、8080、8443是否被占用
4. 查看日志文件了解详细错误信息

### Q: 网站访问还是很慢？
A: 尝试以下解决方案：
1. 检查程序状态是否为"运行中"
2. 点击"刷新节点"重新扫描
3. 在节点管理中手动测试节点
4. 确认DNS或代理配置正确

### Q: 浏览器显示证书错误？
A: 这是正常现象，解决方法：
1. 按照上述步骤安装CA证书
2. 重启浏览器
3. 如果仍有问题，尝试清除浏览器缓存

### Q: 某些网站无法访问？
A: 可能原因：
1. 网站不在支持列表中（可手动添加节点）
2. 网站本身有问题
3. 防火墙阻止了连接

### Q: 如何添加新网站支持？
A: 在节点管理中：
1. 点击"添加节点"
2. 选择站点类型或选择"其他"
3. 输入IP地址和域名
4. 点击"测试"验证可用性

## 🔧 高级配置

### 修改端口
编辑 `src/config/settings.py`：
```python
DNS_PORT = 5353      # DNS端口
PROXY_PORT = 8080    # HTTP代理端口  
HTTPS_PROXY_PORT = 8443  # HTTPS代理端口
```

### 添加支持网站
在 `SUPPORTED_SITES` 中添加新网站配置：
```python
"example.com": {
    "name": "Example Site",
    "domains": ["example.com", "www.example.com"],
    "test_url": "https://example.com",
    "icon": "network"
}
```

### 调整扫描间隔
修改 `settings.py` 中的时间配置：
```python
MONITOR_INTERVAL = 60      # 监控间隔（秒）
SPEED_TEST_INTERVAL = 300  # 测速间隔（秒）
```

## ⚠️ 注意事项

1. **合法使用**: 请遵守相关法律法规和网站服务条款
2. **网络安全**: 不要在不信任的网络环境中使用
3. **证书安全**: CA证书仅用于本地代理，请妥善保管
4. **性能影响**: 代理会增加一定的网络延迟
5. **兼容性**: 某些网站可能有特殊限制
